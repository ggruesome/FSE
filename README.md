# 🎮 Fine Motor Rehabilitation Arcade (F.M.R. Arcade)

A browser arcade of three mini-games designed to help players practice **fine motor skills** (precise clicking, dragging, and hand-eye coordination) in a fun, low-pressure way. Built with [p5.js](https://p5js.org/) for **FSE 100 at Arizona State University**.

## 🕹️ Games

| Game | What you do | Skill practiced |
|------|-------------|-----------------|
| 🎈 **Balloon Pop** | Click balloons before time runs out. Watch for fast lightning balloons! | Click accuracy and reaction time |
| 🌸 **Flower Garden** | Drag tools to water, weed, and fertilize your plants | Controlled dragging and precision |
| 🪙 **Coin Collector** | Drag coins into the treasure chest | Grasp and move coordination |

## ✨ Features

- Personal **highscores** for every game
- A **Player Progress** dashboard with rounds completed, games tried, and most played
- Background music and sound effects
- Runs in any modern browser, with no installs for players

## 🚀 Run it

Open the folder in VS Code, right-click `index.html`, and choose **Open with Live Server**.
